# Reglas de BitChord

## Flujo de Trabajo y Git
- **Commits automáticos tras cambios importantes**: Siempre realizar un commit después de completar y verificar cada cambio o funcionalidad importante.
- **Formato de commits**: Utilizar el estándar Conventional Commits (por ejemplo: `feat(...)`, `fix(...)`, `refactor(...)`, `test(...)`).
- **Verificación**: Asegurarse de que el código compile y los tests relevantes pasen antes de realizar el commit.
